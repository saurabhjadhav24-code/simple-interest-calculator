# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates the interest on a principal amount based on the annual rate of interest and time period.

## Features
- Calculates simple interest
- Easy to use
- Accepts principal, rate, and time
- Displays the calculated interest

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal Amount
- R = Annual Rate of Interest
- T = Time Period in Years

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 * 5 * 2) / 100

Simple Interest = 100

Total Amount = 1100
